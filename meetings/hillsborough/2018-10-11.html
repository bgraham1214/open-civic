New to this? How building and land decisions work

  1. Change to the future land-use map

    CPA 18-08 & LDC Amendment 18-0940 - Future Land Use Element Text Change - Legally Nonconforming Mobile Home Parks

    What does “Change to the future land-use map” mean?

    The county's long-range plan has a map saying how each area may be used in the future and how many homes per acre are allowed at most. This changes that map for one area. A rezoning usually comes after. Source. More

    Official wording

    Passed 7 to 0.

  2. Change to the county's development rules

    Land Development Code (LDC) Amendment 18-0940 - Redevelopment of Mobile Home Parks for Affordable Housing Projects

    What does “Change to the development rules” mean?

    The Land Development Code is the county's rulebook for building: lot sizes, setbacks, parking, signs and so on. This changes the rulebook itself, for everyone it applies to. Source. More

    Official wording

    Land Development Code (LDC) Amendment 18-0940 - Redevelopment of Mobile Home Parks for Affordable Housing Projects. So moved to approve LDC Amendment 18-0940.

    Passed 7 to 0.

    Official record: the Clerk's 2018 voting record, page 75. Look for roll call (RCS) 842.
