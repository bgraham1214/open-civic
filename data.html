Data and downloads

Everything on this site is free to download, query and republish. Each record links to the official source it came from.

These are public records, read by software. Votes, amounts and names can be misread: check the official record before relying on a detail, and tell us if something is wrong.

Databases

  • Temple Terrace database

    SQLite, 40 MB. Every archived agenda, packet and minutes page (full-text searchable), agenda items, roll-call votes read from the minutes, contracts, vendors and the change log. Browse it in your browser (downloads the whole file first).

  • County commissions database

    SQLite, 55 MB. Meetings, agenda items and each commissioner's vote for Hillsborough (votes since 2014), Pasco (votes read from the Clerk's minutes) and Hernando (since 2025), with archived document pages. Browse it in your browser (downloads the whole file first).

  • Southeast Volusia cities database

    SQLite, 4 MB. Meetings, agenda items and each council member's vote for Edgewater (from 2025), and Oak Hill's archived agendas and minutes (full-text searchable). Browse it in your browser (downloads the whole file first).

Tables are described inside each database (Datasette shows the descriptions). SQLite opens in Datasette, DB Browser for SQLite, Python, R and most data tools.

People, organisations and meetings

  • Temple Terrace entities

    FollowTheMoney JSON lines, 157 KB. Officials, organisations, contracts and meetings in the open FollowTheMoney format.

  • County entities

    FollowTheMoney JSON lines, 762 KB. Each county and board, each commissioner and their membership, each meeting and archived document.

  • Southeast Volusia entities

    FollowTheMoney JSON lines, 196 KB. Each city and board, each council member and their membership, each meeting and archived document.

FollowTheMoney is the open data model used by OpenSanctions and Aleph. People appear only in their public roles (from roll-call votes), never from public comment.

Raw files and history

The data folder on GitHub holds every listing, the fingerprint log (manifest.jsonl: when each document appeared, changed or was removed) and the extracted text. Copies of every document version are in the files release, named by their SHA-256 fingerprint.

For software and AI tools

A plain-text map of this site is at llms.txt, and every page is listed in sitemap.xml. Pages carry schema.org data (meetings as Events, commissioners as People, terms as DefinedTerms). Please identify your tool and keep request rates low.

Open Civic Web is a free, nonpartisan public project. Every night it collects public records from official government websites and keeps a fingerprinted copy, so anyone can check what was decided and whether a record later changed. Updated November 14, 2026 at 10:33 AM Eastern.
